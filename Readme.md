### <p align='center'>MERN Stack Introduction</p>
- `MongDB` is the nosql database that is used for to store data as a json format.

- `ExpressJS` Framework of the database to build API's and support the Server. in help of ExpressJs we can complete the backend development.

- `ReactJS` is the frontend Javascript Library used for develop frontend. In help of it we can build interactive UI's,

- `NodeJS` is the powerful engine by which we can code javascript in the backend, Nodejs is very fast and scalable.
